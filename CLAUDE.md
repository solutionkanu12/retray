# ReTray Agent Context

This project is a hackathon frontend prototype for NextStep Hacks 2026, Earth Forward. ReTray is global reusable food-packaging infrastructure, not a recycling app, marketplace, or payment product.

The only job of the prototype is to make one container loop feel real: issue RT-024 at Kora Kitchen, show Maya L. a return pass, confirm a simulated return, and update the operational ledger.

The design source of truth is `DESIGN.md`. Read `AGENTS.md` before any change.
