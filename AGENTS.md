# ReTray Working Rules

- Read `PROJECT.md`, `MVP.md`, `DESIGN.md`, `SECURITY.md`, and `STATUS.md` before changing product code.
- Preserve the exact Kora Kitchen, Maya L., RT-024, and EUR 3.00 demo story unless the product owner changes it.
- Prefer a complete core loop over extra features.
- No gradients, glass, glow, green eco cliches, generic recycling symbols, or AI-generated food imagery.
- No emojis, exclamation marks, em dashes, or en dashes in UI or README copy.
- Never imply real payments, authentication, scanning hardware, location, or production availability.
- Use meaningful tests for state transitions and interactions.
- Keep Git commits authored by Solution only.
